# Реализация стека (Stack) на Python

Этот проект представляет собой реализацию структуры данных **Стек** (Stack) на языке Python. Стек работает по принципу **LIFO** (Last In, First Out) — «последним пришёл, первым вышел».

## Структура проекта

Код состоит из двух классов:

*   **`StackIsEmptyError`** — пользовательское исключение, которое выбрасывается при попытке извлечь элемент из пустого стека.
*   **`Stack`** — основной класс, реализующий логику работы стека.

### 1. Инициализация (`__init__`)
При создании стека вы можете сразу передать в него элементы. Все переданные аргументы будут добавлены в стек в том порядке, в котором они указаны.

```python
s = Stack(1, 2, 3)  # В стеке: [1, 2, 3]
```

### 2. Добавление элемента (`push`)
Добавляет новый элемент на вершину стека.
*   **Сложность:** O(1).

```python
s.push(4)  # В стеке: [1, 2, 3, 4]
```

### 3. Извлечение элемента (`pop`)
Удаляет и возвращает элемент с вершины стека.
*   **Исключение:** Если стек пуст, выбрасывается ошибка `StackIsEmptyError`.
*   **Сложность:** O(1).

```python
last = s.pop()  # Вернёт 4, в стеке останется: [1, 2, 3]
```

### 4. Просмотр вершины (`top`)
Возвращает верхний элемент стека, но **не удаляет** его.
*   **Внимание:** Если стек пуст, метод вызовет ошибку `IndexError` (так как обращается к последнему элементу списка напрямую).

```python
top_el = s.top()
```

### 5. Проверка на пустоту (`is_empty`)
Возвращает `True`, если стек пуст, и `False` в противном случае.

```python
if s.is_empty():
    print("Стек пуст")
```
### 6. Размер стека (`size`)
Возвращает текущее количество элементов в стеке.

```python
print(s.size())
```

### 7. Печать стека (`print_stack`)
Выводит текущее содержимое стека в консоль в виде списка.

```python
s.print_stack()  # Выведет: [1, 2, 3]
```
